Core Paradigm Shift: Pets vs. Cattle in AI Agents
The architectural transformation powering Managed Agents
Apr 2026
❌ The Old Paradigm: The Agent as a "Pet" Fragile
  • Brain, Harness, Sandbox, and Credentials all crammed inside one container.
  • If the container dies, the session is irreversibly lost.
  • Customer VPC integration requires peering entire networks.
  • Tokens are stored inside sandbox → prompt injection can exfiltrate keys.
  • Every session pays heavy container boot cold-start penalty on TTFT.
✅ The New Paradigm: Decoupled Brain, Hands & Session Resilient
  • The Brain (LLM + Harness): Stateless! Reboots with wake(sessionId).
  • The Hands (Sandboxes/MCP): Cattle! Called via execute(name, input).
  • The Session (External Event Log): Interrogated via getEvents().
  • Security Boundary: Tokens and credentials never enter the sandbox.
  • Lazy sandbox provisioning → 60% faster p50 TTFT, >90% p95.

🎯 Agent-Computer Interface (ACI) & Poka-Yoke Design
Why tool specification matters more than system prompt engineering
SWE-bench Lessons
Bad Tool Design (High Error Rate):
edit_file(path: "utils.py", diff: "@@ -12,4 +12,6 @@...")
Problem: Model must accurately predict chunk line counts before writing new code, and gets lost when relative paths change.
Poka-Yoke Tool Design (Flawless Execution):
edit_file(absolute_path: "/project/src/utils.py", old_string: "...", new_string: "...")
Solution: Requires absolute filepaths, eliminates line-count calculations, and matches internet training distribution.
SWE-bench Verified Impact
Anthropic's team spent more time optimizing tool definitions than prompts. Eliminating relative paths and complex diff syntax produced the largest single jump in automated benchmark scores.
