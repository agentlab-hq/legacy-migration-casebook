# Security Policy

## Supported version

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security-advisory reporting for this repository, or contact the maintainers privately through the repository owner profile.

Include a minimal reproduction, impact assessment, and any suggested mitigation. We will acknowledge reports within 7 days and coordinate a fix before public disclosure where appropriate.
