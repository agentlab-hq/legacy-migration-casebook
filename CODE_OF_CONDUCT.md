# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background or identity.

## Expected behavior

Use welcoming language, respect differing viewpoints, give and accept constructive feedback, and focus on what is best for the community.

## Unacceptable behavior

Harassment, threats, personal attacks, publication of private information, or other conduct that could reasonably be considered inappropriate are not acceptable.

## Enforcement

Report unacceptable behavior privately to the repository maintainers. Reports will be reviewed promptly and handled fairly.

This code of conduct is adapted from the Contributor Covenant, version 2.1.
