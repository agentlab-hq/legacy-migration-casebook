# Public roadmap

## Now — reliable adoption

- Installable policy CLI with structured decisions
- JSONL audit logs and Markdown reports
- Local development, CI review, and production-restricted presets
- Reusable GitHub Action

## Next — team workflows

- Approval handoffs for blocked actions
- Policy packs for common engineering environments
- Integration examples for MCP-compatible tools and CI providers
- Compatibility and threat-model documentation

## Later — governance at scale

- Shared policy management
- Central audit analysis and reporting
- Self-hosted deployment guidance

This roadmap is intentionally outcome-focused. Community feedback and real adopter needs determine priority.
